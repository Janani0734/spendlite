# SpendLite

AI-assisted expense management platform for small companies: track expenses, set budgets, get spend insights.

> Status: under active development (Milestone 1: backend foundation).

## Tech stack

- Backend: Node.js, Express, TypeScript, Prisma
- Database: PostgreSQL 16
- Frontend: React, TypeScript, Vite (planned)
- DevOps: Docker, GitHub Actions (planned)

## Repository layout

    spendlite/
    ├── backend/      Express + TypeScript API
    ├── frontend/     React app (planned)
    └── docker-compose.yml
